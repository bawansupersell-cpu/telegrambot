بۆتی تلگرامی زیرەکی دەستکرد (Claude)
====================================
هیچ پاکێجێکی زیادە ناوێت، تەنها Python 3.9+.

١) بۆتی تلگرام دروست بکە: لە تلگرام @BotFather بکەرەوە، /newbot بنووسە، تۆکنەکە (telegram_token) هەڵبگرە.
٢) کلیلی API وەربگرە: console.anthropic.com ← API Keys ← Create Key، و لە Billing باڵانس زیاد بکە.
   (ئەمە جیایە لە بەشداریکردنی Claude.ai؛ پارەدانی API بەپێی بەکارهێنان دەبێت.)
٣) run.bat بکەرەوە. یەکەمجار config.json دروست دەکات. بیکەرەوە و telegram_token و anthropic_api_key دابنێ،
   پاشان دووبارە run.bat.
٤) لە تلگرام /id بنووسە بۆ بۆتەکە، ژمارەکە بخەرە ناو "allowed_user_ids": [123456789] و بۆتەکە دووبارە دەست پێ بکە.
   (بێ ئەمە هەرکەسێک بۆتەکەی بدۆزێتەوە لەسەر باڵانسی تۆ بەکاری دەهێنێت.)

فەرمانەکان: /new گفتوگۆی نوێ | /usage تۆکنی ئەمڕۆ | /id | /help
وێنەش دەتوانیت بنێریت.

ڕێکخستنەکان (config.json)
 model: "claude-sonnet-5-5" (باش و ئەرزان) یان "claude-opus-5-5" (بەهێزتر، گرانتر)
 daily_token_budget: 0 = بێسنور؛ بۆ نموونە 200000 بۆ ئەوەی باڵانس نەسوتێت
 history_messages: چەند نامەی پێشوو لەبیر بێت
 system_prompt: ڕەفتاری بۆتەکە

بۆ ئەوەی هەمیشە کار بکات: لەسەر VPS یان کۆمپیوتەرێکی هەمیشە-ڕووناک ڕای بکە.
